Use order of tasks. If task A comes before B, then a probability can be defined for a plausibility, e.g. 0.7-0.9. If a task B cannot happen before C, then probability is lowered, e.g. 0.1-0.3.
Both voter and score are necessary for different purposes. Voter detects which node is differs in its result (for possible error detection) and plausibility reference checks whether a valid result may be used.
