# Thesis Structural Outline (Prof. Dr. Facchi)

1. **Title Page** (*Titelseite*)
   - Contains title, author, supervisor, date, and institution designation.

2. **Declaration of Authorship** (*Erklärung der Selbstständigkeit*)
   - Formal statement of independent work.

3. **Abstract / Summary** (*Zusammenfassung*)
   - High-level overview of the thesis scope, methodology, and core results.

4. **Table of Contents** (*Inhaltsverzeichnis*)

5. **Introduction** (*Einleitung*)
   - Problem statement & task definition (*Aufgabenstellung*).
   - Motivation and objectives.
   - Explicit separation of own contributions from existing prior work.

6. **Main Chapters** (*Inhaltskapitel / Hauptteil*)
   - Logical breakdown of research and development (e.g., following software engineering/system design phases: elaborate on scope decisions / reasoning and iterative development of resulting architecture).

7. **Conclusion & Evaluation** (*Schlusskapitel*)
   - Summary of outcomes.
   - Critical evaluation of the solution.
   - Outlook on future work (*Ausblick*).

8. **Bibliography** (*Literaturverzeichnis*)

9. **Appendix** (*Anhang*)
   - Supplementary materials (e.g., extended code listings, user manuals, datasets, AI usage documentation sheet).
