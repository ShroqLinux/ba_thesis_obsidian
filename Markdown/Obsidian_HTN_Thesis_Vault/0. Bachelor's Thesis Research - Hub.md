# 🛸 Bachelor's Thesis Research: Distributed HTN Planning with TMR Redundancy

**Core Topic:** Concept of an architectural design running [[2. Introduction to HTN|Hierarchical Task Network (HTN)]] planning in a distributed node cluster using [[6. Bridge to Redundancy|Triple Modular Redundancy (TMR)]] for deterministic aerial / avionics systems.

**Method of writing:** Outline architecture grounded in the core concept of [[6. Bridge to Redundancy|TMR]] with connection to domain-relevant constraints which are necessary in systems using determinism and running safety-critical applications. Cross-reference them to sources making use of the same concepts in the same or an adjacent field.

---

## 🗺️ Navigation & Research Sections

- **[[2. Introduction to HTN]]** — Problem framing, automated planning foundations, task/method decomposition, and initial state definitions.
- **[[1. Decisions log]]** — Complete chronological ledger of system scoping, redundancy models, and architectural decisions.
- **[[3. Planning Systems]]** — SHOP and SHOP2 planner lineage, partial ordering, and GTPyhop implementation baseline.
- **[[4. Wireless communication & coordination]]** — Network management tradeoffs, wireless vs. airborne constraints, and static cluster framing.
- **[[5. Parallelization of DFS]]** — Splitting decision trees, deterministic DFS, work-stealing, and randomized parallel search analysis.
- **[[6. Bridge to Redundancy]]** — Spatial redundancy, active replication, vector-comparison voter mechanism, watchdog timers, and synchronization layers.
- **[[7. Avionics Standards & Deterministic Buses]]** — Guaranteed message delivery justification (MIL-STD-1553, ARINC 664/AFDX, ARINC 429) and DO-178C alignment.
